TradeMesh — Documentation

Multi-asset trading UI template (stocks / crypto / forex demo dashboard) — installation & file guide.

Frontend Template Demo / Simulated Data Only

1. What This Is

TradeMesh is a front-end UI template for a multi-asset (stocks, crypto, forex) trading dashboard. It includes a landing page, a demo trading dashboard, order modals, a Buy/Sell flow, a wallet panel, and a KYC step flow. All balances, orders, portfolio values, and KYC verification shown in the demo are simulated in the browser — nothing is sent to a real brokerage, bank, or KYC provider.

Crypto prices for BTC, ETH, SOL, BNB, and DOGE are pulled live from Binance's public market-data API and refreshed automatically every 8 seconds. Stock and forex prices remain static demo data. If the live price request fails for any reason (no internet connection, the API being temporarily unreachable, etc.), the page automatically falls back to its last known / built-in static prices instead of showing a blank or broken screen.

3. Installation

  1. Unzip the package to a folder on your computer or server.
  2. Keep index.html, the css folder, and the js folder together in the same directory, exactly as they were unzipped — the paths inside index.html reference css/style.css and js/app.js as relative paths.
  3. Open index.html directly in a browser to preview it locally, or upload the whole folder to any static web host (e.g. Netlify, Vercel, GitHub Pages, cPanel, Nginx, Apache).
  4. No build step, package manager, or server-side code is required — this is a static HTML/CSS/JS site.

Running Locally

You can simply double-click index.html. For the smoothest experience (and to avoid any browser restrictions on local file access), you can also serve the folder with a lightweight local server, for example:

npx serve .
# or
python -m http.server 8080

Then open the printed local address in your browser.

4. File-by-File Notes

index.html

Contains only the page markup — all sections (hero, ticker, market tables, dashboard panels, modals, footer) and links to css/style.css in the <head> and js/app.js at the end of the <body>.

css/style.css

Contains the full visual design: the dark theme color variables (with a light-theme override toggled by the theme switch), typography, the ticker marquee animation, layout grids, modal styling, and responsive breakpoints. Editing colors is done via the CSS custom properties near the top of the file (--bg, --panel, --brand, etc.).

js/app.js

Contains the demo asset data, application state, and all interactive behavior: rendering market tables, the watchlist, the portfolio/holdings/orders panels, the Buy/Sell order modal, the demo wallet (add funds / withdraw), the 3-step KYC flow, 2FA toggle, search, theme toggle, and the live crypto price updater described below.

5. Live Crypto Prices (Binance API)

The file js/app.js includes a small module that polls Binance's public /api/v3/ticker/24hr endpoint for the following pairs every 8 seconds and updates the price, 24h change %, high/low, and volume shown in the UI:

Displayed PairBinance Symbol
BTC/USDTBTCUSDT
ETH/USDTETHUSDT
SOL/USDTSOLUSDT
BNB/USDTBNBUSDT
DOGE/USDTDOGEUSDT

Fallback behavior: if the API request fails (offline, blocked, rate-limited, or Binance is temporarily unreachable), the script simply keeps whatever prices it last had — including the original static demo prices on first load — so the page never shows blank or broken data. It quietly retries again on the next 8-second cycle.

Note for buyers: because this call is made directly from the browser, it depends on the visitor's own network being able to reach api.binance.com. No API key is required for this public, read-only endpoint, and no personal or account data is ever sent to Binance.

6. Customization Tips

  • To change branding/colors: edit the :root variables at the top of css/style.css.
  • To add/remove/edit stock or forex rows: edit the ASSETS.stocks / ASSETS.forex arrays near the top of js/app.js.
  • To add/remove a crypto pair from the live feed: add or remove an entry in ASSETS.crypto and the matching line in the BINANCE_SYMBOL_MAP object in js/app.js.
  • All amounts, KYC, and wallet actions are simulated client-side only — connecting them to a real brokerage, payment gateway, or KYC/identity provider would require a licensed backend integration, which is outside the scope of this template.

7. Important Disclaimer

This template is a UI/demo product only. It does not execute real trades, move real money, perform real KYC/identity verification, or connect to any licensed brokerage, bank, or exchange account. Anyone deploying this as a real financial product is responsible for obtaining the appropriate licenses/approvals from their local financial regulator and for building a real, secure backend — none of which is included in this package.
